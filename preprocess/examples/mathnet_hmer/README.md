# MathNet HMER Pipeline Example

This directory contains a minimal example for
`preprocess/make_mathnet_hmer_data.py`, which ports
`mathnet-ly/0410_proc_file.ipynb` into a reusable CLI.

## Files

- `sample_caption.txt`: text input in `image_id caption...` format
- `sample_items.json`: JSON input using `img_id` and `label`
- `images/`: sample images referenced by the generated outputs
- `test_formula.ipynb`: personal processing test notebook adapted to the current repo layout
- `processed_output/`: example output generated by the `process` subcommand
- `prompt_only_output/`: example output generated by the `prompt-only` subcommand

## Reproduce the Processed Output

Run from the repository root:

```bash
python preprocess/make_mathnet_hmer_data.py process \
  --input preprocess/examples/mathnet_hmer/sample_caption.txt \
  --output-dir preprocess/examples/mathnet_hmer/processed_output \
  --image-base-path preprocess/examples/mathnet_hmer/images \
  --image-suffix .png \
  --mathnet-root preprocess/MathNet4clean
```

## Reproduce the Prompt-Only Output

```bash
python preprocess/make_mathnet_hmer_data.py prompt-only \
  --input preprocess/examples/mathnet_hmer/sample_caption.txt \
  --output-dir preprocess/examples/mathnet_hmer/prompt_only_output \
  --image-base-path preprocess/examples/mathnet_hmer/images \
  --image-suffix .png
```

The sample keeps one deliberately invalid caption (`求 x`) so the example also
shows how `invalid_record.json` is populated by the pipeline.

`test_formula.ipynb` is intended for interactive debugging of
`improve_tokens_unimumer.py` on individual formulas and on a copied sample JSON
file.
